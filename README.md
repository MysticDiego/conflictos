# Conflictos

Práctica de Desarrollo de Software V para trabajar con Git y un repositorio compartido.

El programa `Conflicto1.java` solicita tres números enteros (A, B y C), siguiendo el código visible en las fotos de clase. La clase se llama `Conflicto1` para coincidir con el archivo local. No realiza operaciones adicionales.

## Clonar

```bash
git clone https://github.com/MysticDiego/conflictos.git
cd conflictos
```

## Compilar y ejecutar

Requiere un JDK instalado, con `javac` y `java` disponibles en la terminal.

```bash
javac -encoding UTF-8 Conflicto1.java
java Conflicto1
```

Introduce un número entero cuando se solicite cada valor.

El repositorio público se puede clonar sin invitación. Para subir cambios directamente, el propietario debe otorgar acceso de colaborador a la cuenta de la otra persona.
